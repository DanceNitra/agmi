# Security policy

agmi measures whether memory stores notice tampering. Most of what it finds
is a documented design gap and is discussed in public issues.

If you believe you have found an actual vulnerability in a target library
using this suite (for example a deserialization path that executes code),
do not open a public issue. Email yasha.khandelwal@tech4biz.io with the
details and we will coordinate disclosure with that project's maintainers.
